# Task 2
(1) Why does the initial and final value of the shield power remain unchanged? 
(2) Why does the order of output change every time you run the program? 

1. The fork() function makes a full copy of the process, including its variables.
Any changes to a variables state in a child process does not affect the parent
process. That includes other child processes as well.

2. Parent/child process execution occurs outside of their control. Since they are
running as independent processes, the operating system is deciding which running
processes get execution time. Sibling processes also don't have any way to synchronize.
